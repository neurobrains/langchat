## Quick Install

```bash
pip install langchat
```

<Callout type="info">
Requires Python 3.8 or higher.
</Callout>

## Verify Installation

Test it works:

```python
import langchat
print(langchat.__version__)  # Should print: 2.0.0
```

## Virtual Environment (Recommended)

Always use a virtual environment:

<CodeGroup>
```bash Linux/macOS
python -m venv venv
source venv/bin/activate
pip install langchat
```

```bash Windows
python -m venv venv
venv\Scripts\activate
pip install langchat
```
</CodeGroup>

## System Requirements

- **Python**: 3.8 or higher (3.10+ recommended)
- **OS**: Windows, macOS, or Linux
- **RAM**: 2GB minimum (4GB+ recommended)

<Callout type="warning">
The reranker downloads models (~50MB) on first use. Make sure you have internet and disk space.
</Callout>

## What You Need

Before using LangChat, get these accounts:

1. **OpenAI**: [platform.openai.com](https://platform.openai.com) - For AI models
2. **Pinecone**: [pinecone.io](https://pinecone.io) - For search (create an index)
3. **Supabase**: [supabase.com](https://supabase.com) - For storing chat history

## Class: LangChat

Main interface for using LangChat.

### Constructor

```python
LangChat(
    llm,
    vector_db,
    db,
    reranker=None,
    prompt_template=None,
    standalone_question_prompt=None,
    verbose=False,
    max_chat_history=20
)
```

**Parameters:**

<Param name="llm" type="Any" required>
  LLM provider instance (e.g., OpenAI, Anthropic, Gemini)
</Param>

<Param name="vector_db" type="Any" required>
  Vector database provider (e.g., Pinecone)
</Param>

<Param name="db" type="Any" required>
  Database provider (e.g., Supabase)
</Param>

<Param name="reranker" type="Any" default="None">
  Optional reranker provider
</Param>

<Param name="prompt_template" type="str | None" default="None">
  Custom system prompt template
</Param>

<Param name="standalone_question_prompt" type="str | None" default="None">
  Custom standalone question prompt
</Param>

<Param name="verbose" type="bool" default="False">
  Enable verbose logging
</Param>

<Param name="max_chat_history" type="int" default="20">
  Maximum chat history messages
</Param>

**Example:**

```python
from langchat import LangChat
from langchat.llm import OpenAI
from langchat.vector_db import Pinecone
from langchat.database import Supabase

llm = OpenAI(api_key="sk-...", model="gpt-4o-mini")
vector_db = Pinecone(api_key="...", index_name="...")
db = Supabase(url="https://...", key="...")

ai = LangChat(llm=llm, vector_db=vector_db, db=db)
```

### Methods

#### `async chat()`

Process a chat query.

```python
async def chat(
    self,
    query: str,
    user_id: str,
    domain: str = "default"
) -> dict
```

**Returns:**

`dict` with:
- `response` (str): AI response
- `status` (str): "success" or "error"
- `response_time` (float): Time in seconds

#### `chat_sync()`

Synchronous version of chat.

```python
def chat_sync(
    self,
    query: str,
    user_id: str,
    domain: str = "default"
) -> dict
```

#### `load_and_index_documents()`

Index documents to Pinecone.

```python
def load_and_index_documents(
    self,
    file_path: str,
    chunk_size: int = 1000,
    chunk_overlap: int = 200,
    namespace: Optional[str] = None,
    prevent_duplicates: bool = True
) -> dict
```

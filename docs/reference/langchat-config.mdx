## Overview

LangChat uses direct provider initialization. Configure each provider separately.

## LLM Providers

```python
from langchat.llm import OpenAI, Anthropic, Gemini

llm = OpenAI(api_key="sk-...", model="gpt-4o-mini")
```

## Vector Database

```python
from langchat.vector_db import Pinecone

vector_db = Pinecone(api_key="...", index_name="...")
```

## Database

```python
from langchat.database import Supabase

db = Supabase(url="https://...", key="...")
```

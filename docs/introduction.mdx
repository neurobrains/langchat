## Quick Example

Here's how simple it is:

```python
from langchat import LangChat
from langchat.llm import OpenAI
from langchat.vector_db import Pinecone
from langchat.database import Supabase

# Setup (one time)
llm = OpenAI(api_key="sk-...", model="gpt-4o-mini")
vector_db = Pinecone(api_key="...", index_name="my-index")
db = Supabase(url="https://...", key="...")

# Create chatbot
ai = LangChat(llm=llm, vector_db=vector_db, db=db)

# Use it
result = await ai.chat(
    query="What can you help me with?",
    user_id="user123"
)
print(result["response"])
```

That's it! In just a few lines, you have a fully functional chatbot with search, memory, and AI capabilities.
</Callout>

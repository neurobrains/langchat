## Quick Start

Get your chatbot running in 5 minutes:

<CodeGroup>
```python Complete Example
import asyncio
from langchat import LangChat
from langchat.llm import OpenAI
from langchat.vector_db import Pinecone
from langchat.database import Supabase

async def main():
    # Setup providers
    llm = OpenAI(api_key="sk-...", model="gpt-4o-mini", temperature=0.7)
    vector_db = Pinecone(api_key="...", index_name="...")
    db = Supabase(url="https://...", key="...")
    
    # Create chatbot
    ai = LangChat(llm=llm, vector_db=vector_db, db=db)
    
    # Chat!
    result = await ai.chat(
        query="Hello! What can you help me with?",
        user_id="user123"
    )
    print(result["response"])

asyncio.run(main())
```

```python API Server
from langchat.api.app import create_app
from langchat.llm import OpenAI
from langchat.vector_db import Pinecone
from langchat.database import Supabase
import uvicorn

# Setup
llm = OpenAI(api_key="sk-...", model="gpt-4o-mini")
vector_db = Pinecone(api_key="...", index_name="...")
db = Supabase(url="https://...", key="...")

# Create server
app = create_app(llm=llm, vector_db=vector_db, db=db)

# Run
uvicorn.run(app, host="0.0.0.0", port=8000)
```
</CodeGroup>

## What You Need

Before starting, get these accounts:

1. **OpenAI** - [platform.openai.com](https://platform.openai.com) - For AI models
2. **Pinecone** - [pinecone.io](https://pinecone.io) - For search (create an index)
3. **Supabase** - [supabase.com](https://supabase.com) - For chat history

<Callout type="warning">
Make sure your Pinecone index exists before running. Supabase tables are created automatically.
</Callout>

## Class: LangChat

Main interface for using LangChat.

### Constructor

```python
LangChat(
    llm,
    vector_db,
    db,
    reranker=None,
    prompt_template=None,
    standalone_question_prompt=None,
    verbose=False,
    max_chat_history=20
)
```

**Parameters:**

<ParamField path="llm" type="Any" required>
  LLM provider instance (e.g., OpenAI, Anthropic, Gemini)
</ParamField>

<ParamField path="vector_db" type="Any" required>
  Vector database provider (e.g., Pinecone)
</ParamField>

<ParamField path="db" type="Any" required>
  Database provider (e.g., Supabase)
</ParamField>

<ParamField path="reranker" type="Any" default="None">
  Optional reranker provider (defaults to Flashrank)
</ParamField>

<ParamField path="prompt_template" type="str | None" default="None">
  Custom system prompt template
</ParamField>

<ParamField path="standalone_question_prompt" type="str | None" default="None">
  Custom standalone question prompt
</ParamField>

<ParamField path="verbose" type="bool" default="False">
  Enable verbose logging
</ParamField>

<ParamField path="max_chat_history" type="int" default="20">
  Maximum chat history messages to keep
</ParamField>

**Example:**

```python
from langchat import LangChat
from langchat.llm import OpenAI
from langchat.vector_db import Pinecone
from langchat.database import Supabase

# Setup providers
llm = OpenAI(api_key="sk-...", model="gpt-4o-mini")
vector_db = Pinecone(api_key="...", index_name="...")
db = Supabase(url="https://...", key="...")

# Create LangChat
ai = LangChat(llm=llm, vector_db=vector_db, db=db)
```

### Methods

#### `async chat()`

Process a chat query.

```python
async def chat(
    self,
    query: str,
    user_id: str,
    domain: str = "default"
) -> dict
```

**Parameters:**

<ParamField path="query" type="str" required>
  User query text
</ParamField>

<ParamField path="user_id" type="str" required>
  User identifier for session management
</ParamField>

<ParamField path="domain" type="str" default="default">
  Domain for conversation context
</ParamField>

**Returns:**

`dict` with:
- `response` (str): AI response
- `status` (str): "success" or "error"
- `response_time` (float): Time in seconds

**Example:**

```python
result = await ai.chat(
    query="What is Python?",
    user_id="user123",
    domain="default"
)
print(result["response"])
```

#### `load_and_index_documents()`

Index documents to Pinecone.

```python
def load_and_index_documents(
    self,

    chunk_overlap: int = 200,

    prevent_duplicates: bool = True

```

**Returns:**

`dict` with:
- `chunks_indexed` (int): Number of chunks indexed
- `chunks_skipped` (int): Number of duplicates skipped
